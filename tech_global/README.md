# Tech Global Website Application

This directory contains the Next.js application for the Tech Global corporate website.

For the project overview, repository structure, setup instructions, and current implementation notes, see the [repository README](../README.md).

## Local development

From this directory:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Available scripts

- `npm run dev` - Start the development server.
- `npm run build` - Create a production build.
- `npm run start` - Start the production server.
- `npm run lint` - Run ESLint checks.

## Application folders

- `app/` - App Router pages and global styles.
- `components/` - Reusable website sections and UI components.
- `data/` - Service, project, and media content.
- `public/images/` - Static website images.
